# 阅读人格工作台（非虚构 · 单机本地）

把一本书 / 一篇论文 / 一份报告变成可以对话的工作台：左侧读原文，右侧和「作者」或「书中的人」对话；每一句事实都能点回原文；可以联网做研究，但外部信息必须带快照、单独标注。

严格模式下的铁律：

1. **无证据不出事实句**——事实层每个 claim 必须绑定可寻址的 span，否则只能进「解读」或弃权。
2. **作者 ≠ 角色 ≠ 书**——三者是不同对象，证据半径不同，评测集不同。
3. **外部信息必须带快照**——URL + 抓取时间 + 内容哈希 + 逐字引文，缺一不进事实层。

## 快速开始

无需安装任何第三方依赖（Python 3.10+，需要 `numpy`、`lxml`、`python-docx`；本机使用 DSH 内置 Python 3.12）：

```bash
python run.py            # 或 make run
# 打开 http://127.0.0.1:8765
```

首次使用：左侧「＋ 导入文档」上传 `.md/.txt/.html/.epub/.docx/.pdf`。解析完成后自动生成人格（作者、被引述者、案例主体、合成审稿人）。

跑一遍离线演示：

```bash
python demo.py
```

验证全部里程碑：

```bash
python verify.py all     # 或 make verify
```

每个里程碑输出 `eval/scorecard-M*.json`，包含指标、阈值、失败项。

## 它做了什么

| 能力 | 实现 |
|---|---|
| 文档解析 | EPUB/DOCX/HTML/MD/TXT + 自研 PDF（对象表、Flate、ToUnicode、双栏阅读顺序、标题/脚注/页码） |
| 锚点 | `block_id + 偏移 + 前后缀 + 哈希`，重解析可重锚定，失败进 pending 不丢失 |
| 非虚构语义 | 句子级 claim、论证图（thesis / supported_by / contradicts / qualified_by）、实体、引述人、参考文献链接、章节摘要 |
| 检索 | FTS5 + 384 维哈希向量 + RRF + 启发式精排 + 父级扩展 + **证据半径硬过滤** + **强制反证检索** |
| 严格闸门 | G1 结构 / G2 引文逐字 / G3 蕴含 / G4 数字可溯 / G5 限定语保留 / G6 证据半径 |
| 生成 | 两种模式：**严格引用**（逐字 claim + 六道闸门）与**有据改写**（LLM 用检索片段写连贯段落，逐句标 [S#]，数字可回溯，失败自动回退） |
| 作者人格 | 文本作者 / 历史作者双模式；立场表（revised / maintained / acknowledged）；意图问题强制标「解读」 |
| 其他人格 | 被引述者、案例主体、合成审稿人；多人格圆桌；人格间证据隔离 |
| Deep Research | 查询规划、抓取、内容寻址快照、claim 抽取、矛盾检测、事实核查（CONSISTENT / CONFLICT / UNDETERMINED）、注入防御、离线降级 |
| 查询扩展 | 有 BYOK 时先用一次 LLM 调用把问题改写成 3 条互补查询，再多路检索融合 |
| 交互 | 划线即问、引用跳转、Context Board（直接渲染账本）、导出 |

## 项目工作台

- **项目**：一个容器，装多份素材（书/论文/访谈/评论），可增删、可建立关系（相关/引用/反驳/同主题）。
- **项目级会话**：检索范围 = 项目全部素材，引用会标注来源文档。
- **会话历史**：按项目/素材列出，可恢复、改名、删除；首次提问自动生成标题。
- **文档管理**：搜索、改名、标签、删除（级联清理索引/人格/项目关系）。
- **角色管理**：自动解析 + 手动新建/编辑/删除/重解析；多角色模式下一次提问，每个人格一个气泡。
- **研究进上下文**：会话内研究完成后，dossier 自动挂到该会话；下一轮回答会把外部研究写入账本「research」段，有据改写会把它作为带标注的外部背景。
- **跨文档来源标注**：项目里书与评论混排时，改写会区分「书中」与「有评论指出 / 外部研究认为」，不把批评当作者自述。
- **角色重解析**：手动人格可重建证据集与语气样例（被引述次数、代表引文）。
- **开发者模式**：右侧看板列出每一次 expand / retrieve / generate / rewrite 调用的耗时、模型、状态与请求/响应 JSON。

## 三种回答模式

| 模式 | 行为 | 适用 |
|---|---|---|
| 严格引用 | 只输出原文逐字句 + 引用；每个事实句持 claim 过闸门 | 事实核查、引用写作 |
| 有据改写 | LLM 把检索片段改写成 200–500 字连贯回答，逐句标 [S#]；校验编号存在、数字可在所引片段中找到、含数字段落必须有引用；最多重写一次，失败回退严格引用 | 阅读、综述、汇报 |
| 标注解读 | 允许解读，但必须标出「（解读）」 | 意图、评价类问题 |

有据改写的一次真实输出（《毛选》，11.6s）：

> 书中没有直接预测中国未来的具体日程。就文本所论，中国面前摆着两条路：光明的路和黑暗的路……[S1] 因此，中国要有未来，首先要争取光明的前途和光明的命运……[S2]

## 模型接入（BYOK）

默认 `offline`：生成走抽取式 claim，不联网、不需要 key，事实最保守。

设置页可切到「云端 API」：填 Base URL、API Key、模型名（任何 OpenAI 兼容端点）。Key 只写入本机 `vault/settings.json`（权限 600），不会上传；导出备份默认剔除 key。

关键设计：**嵌入 / 精排 / NLI / 解析永远本地**，只有生成可走云端。断网时解析、索引、检索、严格问答全部可用。

```
wb/ingest/               格式解析 → 规范化文档树 → 锚点
wb/semantics/extractor.py 论证结构 / 实体 / 引述 / 参考文献
wb/index/                分块、FTS+向量索引、混合检索、反证检索
wb/context/              账本渲染/解析、预算装配、引用登记
wb/strict/               claim 生成、六道闸门、渲染、弃权、端到端编排
wb/personas/registry.py  作者双模式、立场演化、证据半径
wb/research/             抓取/快照/信任分层/注入检测/ dossier / 事实核查
wb/admin.py              导出导入、删除、崩溃恢复、完整性、离线矩阵、性能基准

```

## 数据与隐私

- 单用户、只听 `127.0.0.1`、无鉴权、无遥测。
- 所有内容在 `vault/`：`meta.db`、`originals/`、`snapshots/`、`traces/`。
- 导出备份：`wb.admin.export_vault`（zip + manifest + 每文件 SHA256），默认不含 API key。
- 删除文档会清掉 blocks/chunks/claims/personas/anchors/highlights/sessions，并扫描残留。

## 验证方式

`verify.py` 用自研 `Checker`（不依赖 pytest），每个里程碑把「冻结 fixture + 指标 + 阈值」跑成 PASS/FAIL。

## 已知边界

- 离线生成是抽取式的：答案偏「原文摘录 + 引用」，不会像大模型那样自由组织语言；接上 BYOK 后可改善，但仍受闸门约束。
- 中文 PDF 依赖字体 ToUnicode；扫描件需要外部 OCR（接口已留，未内置）。
- PDF 版面分析是启发式的：极端排版（三栏、旋转页、公式）可能出错，可在阅读器里人工修正块。
- 浏览器端未接自动化测试；M8 用 HTTP 契约 + 静态 UI 钩子验证，真实点击行为需人工确认。
- 研究抓取默认需要显式 URL 或搜索实现；未配置时明确返回 offline，不伪造结果。
